## 8. Usage System / 사용량 시스템

Certain Pro features — specifically OpenAI-powered AI summaries, text correction, and multilingual meeting translation — operate on a **usage-based system** with a monthly limit.

특정 Pro 기능, 즉 OpenAI 기반 AI 요약, 텍스트 교정 및 다국어 회의 번역은 월별 한도가 있는 **사용량 기반 시스템**으로 운영됩니다.

**Note:** Internally, this mechanism is also referred to as "credits" (for example, in support communications); the app itself displays it to you as "usage." Both terms refer to the same monthly allowance described below.

**참고:** 이 체계는 내부적으로 "크레딧"이라고도 부르며(예: 고객 지원 응대 시), 앱 화면에는 "사용량"으로 표시됩니다. 두 용어는 아래에서 설명하는 동일한 월간 한도를 가리킵니다.

- A usage allowance is granted periodically to active Pro subscribers.
- 활성 Pro 구독자에게는 사용 한도가 주기적으로 부여됩니다.

- Each use of an OpenAI-powered feature consumes a portion of your usage allowance based on usage volume.
- OpenAI 기반 기능을 사용할 때마다 사용량에 따라 한도가 차감됩니다.

- Unused usage allowance does not carry over between billing periods unless otherwise stated.
- 미사용 한도는 별도 명시가 없는 한 다음 결제 주기로 이월되지 않습니다.

- When you reach the usage limit, OpenAI-powered features become unavailable until the next usage allowance is granted. On-device features (WhisperKit STT, Foundation Models summary) remain fully available at all times.
- 사용 한도에 도달하면 다음 사용량이 부여될 때까지 OpenAI 기반 기능을 사용할 수 없습니다. 온디바이스 기능(WhisperKit 음성 기록, Foundation Models 요약)은 항상 이용 가능합니다.

**Private Cloud Compute AI summarization is separate from this usage system.** It does not draw on or deplete the usage allowance described above, and using it does not affect how much allowance you have left for OpenAI-powered features. It is instead subject to its own limit that Apple sets and administers independently; Apple does not disclose an exact remaining count or reset cycle, so we do not state one here (for example, we do not describe it as "daily" or "monthly"). If you select "Automatic" as your summary engine, note that when Private Cloud Compute is unavailable, the app falls back to GPT without asking first, and that use does draw on the usage allowance described above.

**Private Cloud Compute 기반 AI 요약은 이 사용량 시스템과는 별개입니다.** 위에서 설명한 사용 한도를 소모하지 않으며, 이 기능을 사용해도 OpenAI 기반 기능에 남은 사용량에는 영향을 주지 않습니다. 대신 Apple이 독자적으로 정하고 관리하는 별도의 한도가 적용되며, Apple은 정확한 잔여 횟수나 초기화 주기를 공개하지 않으므로 당사도 이를 "일간" 또는 "월간"과 같이 특정하여 안내하지 않습니다. 요약 엔진을 "자동"으로 선택한 경우, Private Cloud Compute를 사용할 수 없을 때는 별도로 묻지 않고 GPT로 전환되며, 이 경우의 사용은 위에서 설명한 사용 한도를 소모한다는 점에 유의하시기 바랍니다.

## 9. Downgrade Policy / 다운그레이드 정책

If you cancel your Cleio Pro subscription or it expires, the following applies:

Cleio Pro 구독을 해지하거나 만료될 경우 다음 사항이 적용됩니다:

- **iCloud sync will be deactivated.** Data already stored locally on your device will be retained, but synchronization across devices will stop. storage optimization, which depends on iCloud sync, will also stop; any audio files still stored only in iCloud remain accessible and downloadable.
- **iCloud 동기화가 비활성화됩니다.** 기기에 이미 로컬로 저장된 데이터는 유지되지만, 기기 간 동기화는 중단됩니다. iCloud 동기화에 의존하는 저장 공간 최적화도 함께 중단되며, iCloud에만 저장된 오디오 파일은 계속 접근 및 다운로드가 가능합니다.

- **OpenAI-powered features will be deactivated.** Cloud-based AI summaries, text correction, and multilingual meeting translation will no longer be available.
- **OpenAI 기반 기능이 비활성화됩니다.** 클라우드 기반 AI 요약, 텍스트 교정 및 다국어 회의 번역을 더 이상 사용할 수 없습니다.

- **Private Cloud Compute AI summarization will also be deactivated.** This engine option requires an active Pro subscription and will no longer be available.
- **Private Cloud Compute 기반 AI 요약도 함께 비활성화됩니다.** 이 엔진 선택지는 활성 Pro 구독을 필요로 하며, 더 이상 사용할 수 없습니다.

- **Existing results are preserved.** Summaries, corrected transcripts, and other content generated while you were a Pro subscriber will remain accessible.
- **기존 결과는 보존됩니다.** Pro 구독 기간 중 생성된 요약, 교정된 음성 기록 및 기타 콘텐츠는 계속 열람 가능합니다.

- **Export functionality will be deactivated.** Markdown and PDF export will no longer be available.
- **내보내기 기능이 비활성화됩니다.** Markdown 및 PDF 내보내기를 더 이상 사용할 수 없습니다.

- **On-device features remain fully available.** Recording, on-device STT, speaker diarization, and on-device AI summaries continue without restriction.
- **온디바이스 기능은 계속 이용 가능합니다.** 녹음, 온디바이스 음성 기록, 화자 분리, 온디바이스 AI 요약은 제한 없이 계속 사용할 수 있습니다.
